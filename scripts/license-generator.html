How It Works

  1. Enter the channel handle the licence is bound to.
  2. Select a plan type: Monthly, Yearly, or Lifetime.
  3. For Monthly/Yearly: pick the expiry date using day/month/year selectors.
  4. For Lifetime: no expiry — the key never expires.
  5. Click Generate — a signed SC1 token is produced.
  6. Send the key to the user. They paste it into StumpCast Studio's licence dialog.
